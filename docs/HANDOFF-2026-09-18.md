## 2. 陷阱（本轮增量，接 09-17 handoff §2；51-54 详见账本 §12）

1. **MetaCmd::Lookup 的 None/Some 二义**：`names: None` = 全量 topic。
2. **KIP-848 keepalive**：未变字段置 null——订阅 null ≠ 退订。
3. **nullable struct 线上原语**（51）：int8 presence 标记，与 flexible
   无关；布局探针不够，须真客户端过一遍（自 round-trip ≠ 互操作）。
4. **franz-go 848 三道门**：ctx opt-in + eager balancer 首位 + 宣告 68
   max≥1；错误码以 kerr/Errors.java 为权威（112 非 57）。
5. **TLA+ 审计位等式 RHS 加括号**（`x' = a \/ b` 解析陷阱）；突变体
   捕获面要落准；TLC `#` 不做跨类型比较。
6. **幂等 last_seq = 批内末序号**（53）：base 语义下多记录批第二批判 45；
   单批会话的 e2e 永远测不出。
7. **终态 fence = epoch 单调**（54）：同 epoch 终态后新事务批/marker
   合法（librdkafka 多事务）；marker 与 produce 跨路径无顺序面——
   marker 先落时后到数据以新 first_offset 重锚 txn_open（LSO 照常锚定，
   60s 自 abort 兜底）。
8. **HeartbeatResult 是快照**：多步组断言读 actor 现值；探针先发齐全部
   请求再 await（串行 await 会撞 rebalance deadline 被 27 冲刷）。
9. **e2e 环境坑**：topic 名勿撞 find 过滤子串；segment_max_bytes 滚动
   按批粒度——单批超限不滚动，produce 须分批 flush；改 server 代码后
   忘 rebuild = 旧二进制假象（本环境 port 占用即此因）。
10. **本环境客户端面**：confluent_kafka 2.15 wheel 禁用 rebalance_cb
    （协作语义改行为断言）、ru 下也过滤已中止数据（ru 对照交 franz-go 档）；
    docker hub 不可达 + 宿主 glibc 2.43 → 容器用宿主二进制 + loader 直启
    override。
