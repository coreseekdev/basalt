## 2. 陷阱（本轮增量，接 09-17 handoff §2）

1. **MetaCmd::Lookup 的 None/Some 二义**：`names: None` = 全量 topic；
   心跳 handler 恒传 `Some(...)`（空订阅传 `Some(vec![])`）。
2. **KIP-848 keepalive 语义**：未变字段置 null（"没变化"）——订阅 null
   ≠ 退订（tri-state 穿透组状态机；franz-go topicsMatch 路径每拍发 null）。
3. **nullable struct 线上原语**：int8 presence 标记（-1 null / 1 存在），
   与 flexible 无关（账本 51）——新增含 nullable struct 的 API 时布局
   探针不够，须真客户端过一遍。
4. **franz-go 848 的三道门**（should848）：ctx 键
   `opt_in_kafka_next_gen_balancer_beta` + balancers[0] ∈ {sticky, range}
   + broker 宣告 68 max≥1。任何一门不满足 = 静默回退 classic（消费照常
   = 验收了错误协议的假绿）。
5. **TLA+ 审计位等式必须给 RHS 加括号**：`x' = a \/ b` 解析为
   `(x' = a) \/ b`——名义 cfg 恒真守卫下吞掉 b 不报错，**只有突变体门禁
   才暴露 unconstrained var**（ConsumerGroup848 OffsetCommit 实证）；
   经典 spec 的 `(zombieApplied \/ ...)` 括号写法是必要的，不是风格。
6. **突变体捕获面要落准**：StaleHeartbeat 的 e 若含 0，突变体先踩
   InvRegisteredEpochBounded 而非预期的审计位——阴性对照的红必须是
   预期不变式的红，否则判别力叙事断裂。
7. **TLC 跨类型比较**：`#` 不做 string↔int 比较——成员取整数（Range
   需全序）时占位符 NoOwner 须同型（取 0）。
