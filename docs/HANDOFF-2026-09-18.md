## 2. 陷阱（本轮增量，接 09-17 handoff §2）

1. **MetaCmd::Lookup 的 None/Some 二义**：`names: None` = 全量 topic；
   心跳 handler 恒传 `Some(...)`（空订阅传 `Some(vec![])`）。
2. **KIP-848 keepalive 语义**：客户端对未变字段置 null（"没变化"）——
   订阅 null ≠ 退订（tri-state 传递到组状态机；franz-go topicsMatch 路径
   每拍都发 null，误判 = 成员每拍丢分配）。
3. **nullable struct 线上原语**：int8 presence 标记（-1 null / 1 存在），
   与 flexible 无关；codec 曾缺此原语（账本 51）——新增含 nullable
   struct 的 API 时布局探针不够，须真客户端过一遍。
4. **franz-go 848 的三道门**（should848）：ctx 键
   `opt_in_kafka_next_gen_balancer_beta` + balancers[0] ∈ {sticky, range}
   + broker 宣告 68 max≥1。任何一门不满足 = 静默回退 classic，消费照常
   工作但验收的是错误协议。
5. **&String/.clone() 歧义**（语言面）：迭代器解构出的引用调 `.clone()`
   可能经 `impl Clone for &T` 得到引用——反查 helper 用 `.to_string()`。
