## 3. 关键架构知识

### 3.1 状态面拓扑

```
ClusterState（topics/assignments/leaders）
  → Controller WAL/raft → 所有 broker 200ms 快照拉取
  → ✅ HA（raft 复制 + failover）

Partition 数据（segments）
  → leader 写 → follower 拉 → ISR 多数确认
  → ✅ HA（多副本 + failover 选举）
  → 本地 retention：时间（BASALT_LOG_RETENTION_MS，默认 7d）+ 字节
    （BASALT_LOG_RETENTION_BYTES，默认不限）；sweep 周期
    BASALT_RETENTION_SWEEP_MS（默认 30s）；分层分区生命周期归对象侧

磁盘安全（A2/A3 联动）
  → ENOSPC 事后降级（P0-3）+ 水位前置降级（A2，默认 95%）
  → read_only 拒 produce、fetch 照常；空间释放后 sweep 自动恢复

组协调状态（members/offsets/share cursor）
  → 单 broker 内存 + 本地文件
  → ❌ 无跨 broker 复制（Track B 方案 B 实施后闭合）
```

### 3.2 通道拓扑

```
每分区独立 actor（mpsc 1024）→ 数据面分区间隔离 ✓
GroupManager（mpsc 512）→ 组面单 actor
CG848 actor（mpsc 256）→ 848 组面
MetaService（mpsc 256）→ 元数据面
Controller（mpsc 256）→ 控制面
TxnCoordinator（mpsc 256）→ 事务面
```

解耦结论：数据面过载**不会**拖死管理面。真实风险 = 连接内混用（账本 58
已修）+ 管理面单 actor 挤占（多节点规模化显性）。

### 3.3 端口约定（陷阱 26）

```
主口 = BASALT_PORT（默认 9092）
内部口 = 主口 + 1（9093）——metrics/测试端口必须避开
metrics = BASALT_METRICS_PORT（默认 9094；0 = 关）
```

## 4. 构建陷阱（累计，按会话序）

### 09-18（§2 既有）

1-16 条见 git 历史版本本文档（MetaCmd 二义 / 848 三道门 / TLA+ 括号 /
幂等 last_seq / 通告地址 / 节流串行化 / select 空臂等）。

### 09-19 第一轮（17-22）

17. **账本 58**：produce 处理序乱序 → OOOSN 自激级联。吞吐优化先查处理序缺陷。
18. **账本 59**：CreateTopics 参数被默认覆盖 → EnsureTopic。
19. **账本 60**：空日志 read NotFound → 兜底 15 → 消费死循环。兜底错误码就是客户端行为的编程。
20. **账本 61**：SCRAM nonce 字符集非法 → Java 严格解析失败。最严苛解析器 = 互操作验收必要面。
21. **账本 62**：单节点重启 MetaService 空簇 → 启动 refresh。「重启后第一个请求」与「最后一个」同构测试。
22. PARTITION_GAUGES 类型：Mutex<BTreeMap> 而非 Mutex<Option<...>>。

### 09-19 第二轮（23-27，本轮增量）

23. **账本 64**：稀疏索引（INDEX_INTERVAL_BYTES 边界落项）的末项 ≠ 段内最大
    时间戳——「索引说什么」与「段里有什么」之间有 encoding gap。时间类判定
    必须有不依赖索引的独立信号（mtime）作合取；单信号判删即误删。
24. **账本 65**：编码器按计划字段名查值、查不到**静默写默认值**（空串）——
    请求字段名必须以官方协议 JSON 为唯一权威；入口必须校验（空名 topic）。
    协议字段名常见坑：metadata 请求/响应元素均为 `Name`（非 Topic）；
    DeleteTopics v6 请求 = `Topics[]{Name,TopicId}`；DescribeGroups 的
    Groups 是扁平 string 数组（非结构体数组）。
25. e2e 脚本清理遗留进程用 `pkill -x <进程名>`（精确名匹配）；`pkill -f`
    的模式会匹配到脚本自身的快照包装命令行 → 自杀，复合命令静默中断
    （中断点之后的命令——包括 cargo build——根本没跑，「改了没生效」假象）。
26. 端口撞车：内部口 = BASALT_PORT+1。run_e2e 系 METRICS_PORT=0 缺省的
    原因就是历史撞过 9093；新增监听面先查「端口 +1/+2 占用约定」。
27. 改默认值的连锁面：fsync 默认档翻转影响 bench 基线（-17%）与 e2e 语义
    覆盖（现有脚本自然覆盖生产默认 = 更好）；改默认必须同步 BENCHMARKS.md
    与文档注释。
