## 3. 关键架构知识

### 3.1 状态面拓扑

```
ClusterState（topics/assignments/leaders）
  → Controller WAL/raft → 所有 broker 200ms 快照拉取
  → ✅ HA（raft 复制 + failover）

Partition 数据（segments）
  → leader 写 → follower 拉 → ISR 多数确认
  → ✅ HA（多副本 + failover 选举）

组协调状态（members/offsets/share cursor）
  → 单 broker 内存 + 本地文件
  → ❌ 无跨 broker 复制（方案 B 实施后闭合）
```

### 3.2 通道拓扑

```
每分区独立 actor（mpsc 1024）→ 数据面分区间隔离 ✓
GroupManager（mpsc 512）→ 组面单 actor
CG848 actor（mpsc 256）→ 848 组面
MetaService（mpsc 256）→ 元数据面
Controller（mpsc 256）→ 控制面
TxnCoordinator（mpsc 256）→ 事务面
```

解耦结论：数据面过载**不会**拖死管理面（actor 分离 + fetch pending 化）。
真实风险 = 连接内混用（账本 58 已知情）+ 管理面单 actor 挤占（多节点规模化显性）。

### 3.3 TLA+ 规约索引

| 规约 | 建模 | 状态 |
|---|---|---|
| BasaltDataPlane.tla | 数据面 produce/fetch/replicate | ✅ 绿 |
| ConsumerGroup.tla | classic 四态机 + fencing | ✅ 绿 |

| TransactionCommit.tla | 两阶段事务 + marker + LSO | ✅ 绿 + 两突变体红 |

16. 吞吐类缺陷双重表现互为掩护

### 09-19（本轮增量）

17. **账本 58**：produce 并发派发 → 同分区乱序 → OOOSN → PID reload 级联。
    PRODUCE 读循环内联。**吞吐优化先查处理序缺陷。**
18. **账本 59**：CreateTopics 参数被默认覆盖 → EnsureTopic。
19. **账本 60**：空日志 read NotFound → 兜底 15 → 消费 strip 死循环。
    **兜底错误码就是客户端行为的编程。**
20. **账本 61**：SCRAM nonce 字符集非法 → Java 严格解析整轮认证失败。
    **最严苛解析器 = 互操作验收必要面。**
21. **账本 62**：单节点重启 MetaService 空簇 → 启动 refresh。
    **「重启后第一个客户端请求」与「最后一个」必须同构测试。**
22. **PARTITION_GAUGES 类型**：Mutex<BTreeMap> 而非 Mutex<Option<BTreeMap>>（避免 try_lock 后 get_or_insert 双重 unwrap）。
