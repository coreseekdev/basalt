## 2. 陷阱（本轮增量，接上一份 §2）

1. **MetaCmd::Lookup 的 None/Some 二义**：`names: None` = 全量 topic。
   心跳 handler 按订阅集查询必须恒传 `Some(...)`（空订阅传 `Some(vec![])`）
   ——否则空订阅成员的每次心跳都把全集群 partition_counts 灌进组状态机。
2. **&String 上 `.clone()` 的方法解析歧义**：迭代器 `keys()` 解构后的
   `&String` 调 `.clone()` 会经 `impl Clone for &T` 得到引用而非 String
   （&&T 同族）——反查类 helper 用 `.to_string()` 消歧。
3. **handlers_layout_tests 是嵌套模块**（meta.rs 内 `#[path]` 声明 +
   文件内再开一层 `pub mod`）：引用 meta 私有项用 `use crate::meta::...`
   全路径（`super::` 只到文件级模块层）。
