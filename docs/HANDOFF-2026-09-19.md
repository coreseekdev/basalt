- **franz-go share source 钉死 broker**——客户端 preview 限制（不 re-seed），测试以启动时序规避，服务端无需改。

## 3. 关键架构知识

### 3.1 状态面拓扑（Track B 后）

```
ClusterState（topics/assignments/leaders）
  → Controller WAL/raft → 所有 broker 200ms 快照拉取
  → ✅ HA（raft 复制 + failover；raft 引擎模式有真选举）

Partition 数据（segments）
  → leader 写 → follower 拉 → ISR 多数确认
  → ✅ HA（多副本 + failover 选举）

组协调状态（offsets / share cursor）
  → __basalt_group_state / __share_group_state（内部 topic，produce 路径）
  → ✅ HA（方案 B：协调器 = 分区 leader；切换时重放恢复）
    · GroupManager commit/promote → state_out 通道 → GroupStateSync 转发
      （acks=all，应答 Ok = 已持久化；失败回 CoordinatorNotAvailable）
    · 监督循环（main.rs）：leader==self 且 epoch 变化 → 重放 + BindState
    · share ack 事件 → SHARE_SINK 通道 → 异步下沉（事件丢失 = 重投递，
      KIP-932 至多一次容忍）
```

### 3.2 通道拓扑

```
每分区独立 actor（mpsc 1024）→ 数据面分区间隔离 ✓
GroupManager（mpsc 512）+ state_out 下沉通道 → 组面
CG848 actor（mpsc 256）→ 848 组面（内存态，重启即失 = 重 join 语义）
MetaService（mpsc 256）→ 元数据面
Controller（mpsc 256）→ 控制面（静态模式）/ raft 引擎（raftrs 模式）
TxnCoordinator（mpsc 256）→ 事务面
```

### 3.3 端口约定（陷阱 26）

```
主口 = BASALT_PORT（默认 9092）
内部口 = 主口 + 1（9093）——metrics/测试端口必须避开
metrics = BASALT_METRICS_PORT（默认 9094；0 = 关）
内部口鉴权 = BASALT_INTERNAL_TOKEN（设置后走 v2 HMAC 质询-应答，
  明文握手 fail-closed 拒绝）
```

## 4. 构建陷阱（累计）

### 09-19 第一轮（17-22，Track A 前轮）

17-22 条（produce 处理序 / CreateTopics 默认覆盖 / 兜底错误码 / SCRAM
nonce / 重启首请求 / PARTITION_GAUGES 类型）见 git 历史版本本文档。

### 09-19 第二轮（23-27，Track A）

23. **账本 64**：稀疏索引末项 ≠ 段内最大时间戳——时间判定要有不依赖
    索引的独立信号（mtime）作合取；单信号判删即误删。
24. **账本 65**：编码器按计划字段名查值、查不到静默写默认值——入口必须
    校验；字段名以官方协议 JSON 为唯一权威。
25. e2e 清理遗留进程用 `pkill -x`（精确进程名）；`pkill -f` 会匹配脚本
    自身快照命令行 → 自杀，复合命令静默中断（后续命令没跑 =「改了
    没生效」假象）。
26. 端口撞车：内部口 = BASALT_PORT+1；新增监听面先查「端口 +1/+2 占用
    约定」。
27. 改默认值的连锁面：fsync 翻转影响基准基线与 e2e 语义覆盖——改默认
    必须同步 BENCHMARKS.md 与文档注释。

### 09-20 第四轮（28-31 不变，新增 32）

### 09-19/20 第三轮（28-31，Track B）

28. **账本 66**：协议字段类型审计必须系统性（脚本比对官方 JSON），
    人工逐字段 review 追不上「同族缺陷逐一复发」的节奏（㊿→66 两例）。
29. **账本 67**：终态 ack 无优先级 = 状态机被重复 ack 污染（accept/reject
    双向遮蔽）。共享可变状态机的每个动作都要定义「与既成终态相遇时谁赢」。
30. 多节点 e2e 的场景前提要写进脚本头注释：run_group_failover 依赖
    raft 引擎模式（RAFTRS=raftrs）——批跑忘传参数 = 场景静默退化
    （failover 语义在静态控制器模式下根本不存在）。
31. tokio mpsc 通道元素类型在 async block 内解构时偶发推断失败——
    显式标注 `(Sender<T>, Receiver<T>)` 或先 bind 后解构。
32. **多节点 share 分裂面**（第三会话定位）：组级状态（成员/会话/交付
    游标）驻协调器节点、数据面（ShareFetch/Ack）由客户端发往分区
    leader——单节点同址掩盖一切；跨节点拆分必须先问「每个请求落在
    哪个节点、它有没有该请求所需的状态」。验收资产先行：
    run_share_failover.sh（现为 SKIP/77）+ franz-go failover 模式。
